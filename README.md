AskUI is a German (Karlsruhe-based) company building agentic test automation and computer-use agents for any interface. Its vision agents observe the screen, reason, and act — clicking, typing, and extracting data without DOM queries or brittle UI selectors — across Windows, macOS, Linux, Android, iOS, and embedded/HMI systems. The platform ships a Python Vision Agent SDK, a TypeScript SDK, the AskUI Suite (AgentOS runtime + AskUI Development Environment PowerShell CLI), and the AskUI Hub management console. Developers drive it programmatically through the AskUI Workspaces API — an OpenAPI 3.1 REST service for workspaces, agents, agent executions, access tokens, schedules, runs, files, usage, and billing. AskUI GmbH is ISO/IEC 27001:2022 certified and GDPR-aligned. Surfaced as a Seedcamp portfolio company and enriched into the API Evangelist network.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AskUI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
